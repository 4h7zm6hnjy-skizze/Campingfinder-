# Campingfinder v33.0 – Design-Update

Diese Version setzt die sichtbare App-Oberfläche auf das gewünschte Premium-Design um.

Wesentliche Änderungen:
- großer Campingfinder-Markenheader mit Version und Update-Pill
- KI-Suche / Klassische Suche als große Segmentsteuerung
- große KI-Eingabe und grüner Suchbutton
- kompakte Profilkarte direkt unter der KI-Suche
- Schnellfilter: Familie, Meer, Pool, Hund, Wohnwagen, FKK, Nur Erwachsene
- Karte direkt unter den Schnellfiltern
- Standardansicht zeigt Karte UND Ergebnisliste
- „Karte vergrößern“ schaltet bei Bedarf in eine große Kartenansicht
- neue kompakte Ergebniskarten mit Wetter, Favorit, Badges und Aktionen
- Offizielle Homepage optisch hervorgehoben
- feste 6er-Navigation unten: Finden, Karte, Route, Reise, Meine Plätze, Helfer
- erweiterte Filter bleiben über die klassische Suche erhalten
- Route, Reise, Favoriten, Helfer und alle bestehenden Datenfunktionen bleiben erhalten

Version: 33.0.0
