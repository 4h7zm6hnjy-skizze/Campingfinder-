Campingfinder v31.3

Neu in dieser Version

1. Handy-Optimierung
- Header und Versionsanzeige überlappen nicht.
- KI-Suche passt vollständig in schmale Displays.
- Filterchips bleiben horizontal scrollbar statt abgeschnitten.
- Ergebnisaktionen werden in 1–2 Spalten angeordnet.
- "Offizielle Homepage" bekommt auf dem Handy eine volle Zeile.
- Karte und Liste bleiben innerhalb der Bildschirmbreite.
- Dialoge/Details verwenden maximal die verfügbare Displaybreite.
- Routenplaner, Reise, Budget, Helfer und Formulare werden einspaltig dargestellt.
- Untere Navigation ist scrollbar und überschneidet sich nicht.

2. Tablet-Optimierung
- Header und Navigation passen sich an mittlere Breiten an.
- Karte und Treffer werden untereinander dargestellt.
- Formulare verwenden sinnvoll zwei Spalten.
- Ergebnisaktionen verwenden bis zu drei Spalten.
- Route und Reise bleiben ohne horizontales Abschneiden bedienbar.

3. KI-Suche + Familienprofil
Das gespeicherte Profil wird standardmäßig berücksichtigt:
- Anzahl Erwachsene wird als KI-Kontext übernommen.
- Kinderalter setzt automatisch Baby/Kleinkind/Kinder/Jugendliche-Filter.
- Mit Kindern wird Familienfreundlichkeit berücksichtigt.
- Hund aus dem Profil wird übernommen.
- Wohnmobil/Van/Wohnwagen/Zelt wird aus dem Profil übernommen.
- Direkte Angaben im aktuellen Suchsatz haben Vorrang.
- Unter der KI-Suche wird angezeigt, welches Profil verwendet wird.
- "Profil verwenden" kann für eine einzelne Suche abgeschaltet werden.

4. Offizielle Homepage
Wenn ein Campingplatz im Quelldatensatz eine Betreiber-/Platz-Webseite besitzt,
erscheint in der Trefferkarte und in den Details ein hervorgehobener Button
"Offizielle Homepage". Der Link öffnet direkt die hinterlegte Webseite.
